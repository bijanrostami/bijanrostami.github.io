A personal academic website showcasing research, teaching, and professional information.

## 🌐 Deployment

This website can be easily deployed using:
- **GitHub Pages**: Enable GitHub Pages in repository settings
- **Netlify**: Connect your repository for automatic deployment
- **Vercel**: Import the repository for instant deployment

### GitHub Pages Deployment

1. Go to your repository settings
2. Navigate to "Pages" section
3. Select the branch (usually `main` or `master`)
4. Select the root folder (`/`)
5. Save and wait for deployment

Your site will be available at: `https://[your-username].github.io/[repository-name]/`
